== Overview

This Standard describes an extension for using 2D Tile Matrix Sets in GeoPackage initially developed during the Vector Tiles Pilot OGC initiative sponsored by the US Army Geospatial Center (AGC).

This extension provides alignment with link:http://docs.opengeospatial.org/is/17-083r2/17-083r2.html[OGC Two Dimensional Tile Matrix Set] (OGC 17-083r2),
while also allowing description and sharing of tile matrix sets, including those with variable extents and row widths.
