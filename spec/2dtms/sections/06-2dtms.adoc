=== Tables definition

Following are definitions of the tables for this extension.
As with other GeoPackage tables, this extension takes no position on how either of these tables are to be used by a client.

[[gpkgext_tile_matrix_set]]
==== Definition of the `gpkgext_tile_matrix_set` table

[requirement]
====
[%metadata]
identifier:: /req/core/tile-matrix-set
description:: For describing all 2DTMS
part::
+
--
The GeoPackage SHALL contain a table with the name `gpkgext_tile_matrix_set` and the following columns:

* `id` is a primary key
* `tms` is a human-readable title for the tile matrix set
* `description` is an optional human-readable description for the tile matrix set
* `uri` is a machine-readable URI for the tile matrix set
* `srs_id` is the SRS for the tile matrix set and is a foreign key to `gpkg_spatial_ref_sys.srs_id`
* `min_x`, `min_y`, `max_x`, and `max_y` represent the bounding box of the tile matrix set

as created by the SQL statement:

[source,sql]
----
CREATE TABLE gpkgext_tile_matrix_set (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    tms TEXT NOT NULL,
    description TEXT,
    uri TEXT NOT NULL UNIQUE,
    srs_id INTEGER NOT NULL REFERENCES gpkg_spatial_ref_sys(srs_id),
    min_x REAL NOT NULL,
    min_y REAL NOT NULL,
    max_x REAL NOT NULL,
    max_y REAL NOT NULL
);
----
--
====

[[gpkgext_tile_matrix]]
==== Definition of the `gpkgext_tile_matrix` table

[requirement]
====
[%metadata]
identifier:: /req/core/tile-matrix
description:: For describing the tile matrices of all 2DTMS
part::
+
--
The GeoPackage SHALL contain a table with the name `gpkgext_tile_matrix` and the following columns:

* `id` is a primary key
* `tms_id` is a foreign key to `gpkgext_tile_matrix_set.id`
* `zoom_level` indicates the zoom levels present in the file
* `matrix_width` and `matrix_height` describe the size of the tile matrix in tiles
* `tile_width` and `tile_height` describe the size of each tile in pixels
* `pixel_x_size` and `pixel_y_size` describe the size of each pixel
* `left` and `top` are the top left corner of the tile matrix, which can potentially be different than the tile matrix set
* `scale_denominator` is an optional double representing scale denominator with respect to a "standardized rendering pixel size" of 0.28 mm × 0.28 mm

as created by the SQL statement:

[source,sql]
----
CREATE TABLE gpkgext_tile_matrix (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    tms_id INTEGER NOT NULL REFERENCES gpkgext_tile_matrix_set(id),
    zoom_level INTEGER NOT NULL,
    matrix_width INTEGER NOT NULL,
    matrix_height INTEGER NOT NULL,
    tile_width INTEGER NOT NULL,
    tile_height INTEGER NOT NULL,
    pixel_x_size REAL NOT NULL,
    pixel_y_size REAL NOT NULL,
    left REAL NOT NULL,
    top REAL NOT NULL,
    scale_denominator REAL,
    UNIQUE (tms_id, zoom_level)
);
----
--
====

[[gpkgext_tile_matrix_tables]]
==== Definition of the `gpkgext_tile_matrix_tables` table

[requirement]
====
[%metadata]
identifier:: /req/core/tile-matrix-tables
description:: For associating the tile matrix set tables with entries in the GeoPackage contents
part::
+
--
The GeoPackage SHALL contain a table with the name `gpkgext_tile_matrix_tables` and the following columns: +

* `table_name` is a primary key and also a foreign key to `gpkg_contents.table_name`
* `tms_id` is a foreign key to `gpkgext_tile_matrix_set.id`
* `min_level` and `max_level` are the minimum and maximum zoom levels

as created by the SQL statement:

[source,sql]
----
CREATE TABLE gpkgext_tile_matrix_tables (
    table_name TEXT PRIMARY KEY REFERENCES gpkg_contents(table_name),
    tms_id INTEGER NOT NULL REFERENCES gpkgext_tile_matrix_set(id),
    min_level INTEGER NOT NULL,
    max_level INTEGER NOT NULL
);
----
--
====

[[gpkgext_tile_matrix_variable_widths]]
==== Definition of the `gpkgext_tile_matrix_variable_widths` table

[requirement]
====
[%metadata]
identifier:: /req/core/variable-widths
description:: For supporting variable widths tile matrix sets
part::
+
--
The GeoPackage SHALL contain a table with the name `gpkgext_tile_matrix_variable_widths` and the following columns: +

* `id` is a primary key
* `tm_id` is a foreign key to `gpkgext_tile_matrix.id`
* `min_row` and `max_row` describe the minimum and maximum tile row index where the given coalescence coefficient applies
* `coalesce` is an integer coalescence coefficient

as created by the SQL statement:

[source,sql]
----
CREATE TABLE gpkgext_tile_matrix_variable_widths (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    tm_id INTEGER NOT NULL REFERENCES gpkgext_tile_matrix(id),
    min_row INTEGER NOT NULL,
    max_row INTEGER NOT NULL,
    coalesce INTEGER NOT NULL
);
----
--

=== Views definition

To maintain compatibility with clients that are not aware of this extension, the following views are created.

==== Definition of the `gpkg_tile_matrix_set` view

[requirement]
====
[%metadata]
identifier:: /req/core/view-tile-matrix-set
description:: For maintaining compatibility with clients reading the `gpkg_tile_matrix_set` table
part::
+
--
The GeoPackage SHALL contain a view named `gpkg_tile_matrix_set` defined as follows, as a replacement of the table with the same name from the
https://www.geopackage.org/spec/#_gpkg_tile_matrix_set[GeoPackage Core]:

[source,sql]
----
CREATE VIEW gpkg_tile_matrix_set AS
   SELECT a.table_name, b.srs_id, b.min_x, b.min_y, b.max_x, b.max_y
   FROM gpkgext_tile_matrix_tables a, gpkgext_tile_matrix_set b
   WHERE a.tms_id = b.id`
----
--
====

This view can be added to an existing GeoPackage using the following method:

1. Copy all rows of `gpkg_tile_matrix_set` into `gpkgext_tile_matrix_set`. Where possible, use an existing or well-known tile matrix set.
If the tile matrix set URI cannot be determined, use the table_name as the URI.
2. For each row copied, add a row to `gpkgext_tile_matrix_tables`.
3. `DROP gpkg_tile_matrix_set`.
4. Create the `gpkg_tile_matrix_set` view as described above.

[NOTE]
====
When this view is in place, clients that are not aware of this extension will not be able to add new tile pyramids to the GeoPackage by default.
====

[permission]
====
[%metadata]
identifier:: /per/core/trigger-tile-matrix-set
description:: For maintaining compatibility with clients writing to the `gpkg_tile_matrix_set` table
part::
+
--
The GeoPackage MAY contain a trigger named `gpkg_tile_matrix_set_insert_trigger` defined as follows, to allow clients not supporting this extension to write to the
https://www.geopackage.org/spec/#_gpkg_tile_matrix_set[GeoPackage Core `gpkg_tile_matrix_set`] table:

[source,sql]
----
CREATE TRIGGER gpkg_tile_matrix_set_insert_trigger
INSTEAD OF INSERT ON gpkg_tile_matrix_set
FOR EACH ROW
BEGIN
    INSERT INTO gpkgext_tile_matrix_set (tms, description, uri, srs_id, min_x, min_y, max_x, max_y)
    VALUES (
        'TMS for ' || NEW.table_name,
        'Auto-generated legacy compatibility fallback set',
        'local:tms:generated:' || NEW.table_name,
        NEW.srs_id,
        NEW.min_x,
        NEW.min_y,
        NEW.max_x,
        NEW.max_y
    );

    INSERT INTO gpkgext_tile_matrix_tables (table_name, tms_id, min_level, max_level)
    VALUES (NEW.table_name, last_insert_rowid(), 999, -1);
END;
----
--
====

==== Definition of the `gpkg_tile_matrix` view

[requirement]
====
[%metadata]
identifier:: /req/core/view-tile-matrix
description:: For maintaining compatibility with clients reading the `gpkg_tile_matrix` table
part::
+
--
The GeoPackage SHALL contain a view named `gpkg_tile_matrix` defined as follows, as a replacement of the table with the same name from the
https://www.geopackage.org/spec/#_gpkg_tile_matrix[GeoPackage Core]:

[source,sql]
----
CREATE VIEW gpkg_tile_matrix AS
   SELECT a.table_name, b.zoom_level, b.matrix_width, b.matrix_height, b.tile_width, b.tile_height, b.pixel_x_size, b.pixel_y_size
   FROM gpkgext_tile_matrix_tables a, gpkgext_tile_matrix b
   WHERE a.tms_id = b.tms_id
      AND b.zoom_level >= a.min_level
      AND b.zoom_level <= a.max_level
      AND b.id NOT IN ( SELECT DISTINCT tm_id FROM gpkgext_tile_matrix_variable_widths WHERE coalesce > 1 );
----
--
====

When using this extension, replace this table with a view to maintain compatibility with GeoPackge clients that are not aware of this extension.

This view can be added to an existing GeoPackage using the following method:

1. Copy all rows of `gpkg_tile_matrix` into `gpkgext_tile_matrix`.
Where possible, use an existing or well-known tile matrix set.
If the tile matrix set URI cannot be determined, use the table_name as the URI.
2. `DROP gpkg_tile_matrix`.
3. Create the `gpkg_tile_matrix` view as described above.

[NOTE]
====
This view excludes any tile matrices (zoom level) that contains variable-width rows (where coalesce > 1).
====

[NOTE]
====
When this view is in place, clients that are not aware of this extension will not be able to add new tile pyramids to the GeoPackage by default.
====

[permission]
====
[%metadata]
identifier:: /per/core/trigger-tile-matrix
description:: For maintaining compatibility with clients writing to the `gpkg_tile_matrix` table
part::
+
--
The GeoPackage MAY contain a trigger named `gpkg_tile_matrix_insert_trigger` defined as follows, to allow clients not supporting this extension to write to the
https://www.geopackage.org/spec/#_gpkg_tile_matrix[GeoPackage Core `gpkg_tile_matrix`] table:

[source,sql]
----
CREATE TRIGGER gpkg_tile_matrix_insert_trigger
INSTEAD OF INSERT ON gpkg_tile_matrix
FOR EACH ROW
BEGIN
    INSERT INTO gpkgext_tile_matrix (
        tms_id, zoom_level, matrix_width, matrix_height,
        tile_width, tile_height, pixel_x_size, pixel_y_size,
        "left", "top", scale_denominator
    )
    SELECT
        m.tms_id,
        NEW.zoom_level,
        NEW.matrix_width,
        NEW.matrix_height,
        NEW.tile_width,
        NEW.tile_height,
        NEW.pixel_x_size,
        NEW.pixel_y_size,
        s.min_x,
        s.max_y,
        NULL
    FROM gpkgext_tile_matrix_tables m, gpkgext_tile_matrix_set s
    WHERE m.table_name = NEW.table_name
      AND m.tms_id = s.id;

    UPDATE gpkgext_tile_matrix_tables
    SET
        min_level = (SELECT MIN(zoom_level) FROM gpkgext_tile_matrix, gpkgext_tile_matrix_tables WHERE gpkgext_tile_matrix.tms_id = gpkgext_tile_matrix_tables.tms_id AND gpkgext_tile_matrix_tables.table_name = NEW.table_name),
        max_level = (SELECT MAX(zoom_level) FROM gpkgext_tile_matrix, gpkgext_tile_matrix_tables WHERE gpkgext_tile_matrix.tms_id = gpkgext_tile_matrix_tables.tms_id AND gpkgext_tile_matrix_tables.table_name = NEW.table_name)
    WHERE table_name = NEW.table_name;
END;
----
--
